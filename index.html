MemeWarp 개인정보 처리방침

MemeWarp는 사진을 기기 안에서 재미있게 왜곡하고 밈으로 편집하는 Android 앱입니다. 계정이나 개발자 서버 없이 사용자의 선택에 따라 카메라·사진·저장·공유 기능을 제공합니다.

패키지: com.memewarp.memewarp 적용 버전: 1.0.0 시행일: 2026년 9월 27일

한눈에 보기

  • 계정, 로그인, 광고, 분석 SDK와 개발자 서버가 없습니다.
  • 카메라와 사진은 사용자가 기능을 실행하고 선택한 범위에서만 기기 안에서 처리합니다.
  • 저장과 공유는 사용자가 버튼을 눌렀을 때만 수행합니다.
  • 개발자 서버로 사진을 업로드하거나 보관하지 않습니다.

1. 수집하지 않는 정보

MemeWarp는 계정, 이름, 이메일, 연락처, 위치, 광고 식별자, 분석 식별자 또는 개발자 서버로 전송되는 사진을 수집하지 않습니다. 앱에는 로그인, 백엔드, 분석 SDK, 광고 SDK가 없습니다.

2. 카메라와 사진 사용

사용자가 촬영을 선택하면 카메라 권한을 요청하고 촬영한 사진을 기기 안에서 편집합니다. 갤러리 사진은 Android Photo Picker 또는 운영체제 사진 선택 경로를 통해 사용자가 선택한 사진만 읽습니다. 카메라와 사진 선택은 사용자가 기능을 실행할 때만 사용됩니다.

3. 저장과 공유

사용자가 저장을 누른 경우에만 완성된 PNG를 기기 갤러리에 저장합니다. 사용자가 공유를 누른 경우에만 운영체제 공유 시트를 열며, 실제 수신 앱은 사용자가 선택합니다. MemeWarp 운영자는 공유된 사진을 수신하거나 보관하지 않습니다.

편집 중 생성되는 임시 PNG는 앱 캐시에 기록될 수 있으며 저장·공유 작업이 끝나거나 실패하면 삭제하도록 구현되어 있습니다. 기기 운영체제와 사용자가 선택한 외부 앱의 저장·처리에는 해당 서비스의 정책이 적용됩니다.

4. 제3자 서비스

앱은 Flutter 카메라·사진 선택·갤러리 저장·공유 플러그인을 사용합니다. 이 플러그인들은 사용자가 선택한 운영체제 기능을 연결하며, MemeWarp 운영자 서버로 사진을 업로드하는 기능은 없습니다. 공유 시트에서 사용자가 선택한 앱으로 전달되는 정보는 사용자의 선택에 따른 것입니다.

5. 보안과 보관

개발자 서버에 보관되는 사용자 데이터가 없으므로 개발자 측 삭제 요청 대상 데이터도 없습니다. 갤러리에 저장한 사진은 사용자가 기기에서 관리합니다. 앱 캐시 임시 파일은 작업 종료 시 정리합니다.

6. 아동·민감정보

MemeWarp는 아동의 개인정보를 별도로 수집하지 않습니다. 사용자가 입력하거나 선택한 사진의 내용 자체를 앱 운영자가 확인하지 않습니다. 민감한 사진은 공유 대상과 기기 권한을 사용자가 직접 확인해야 합니다.

7. 정책 변경

앱의 데이터 처리 방식이 변경되면 이 페이지의 시행일과 내용을 갱신합니다. 변경된 정책은 이 페이지에 게시한 날부터 적용됩니다.
